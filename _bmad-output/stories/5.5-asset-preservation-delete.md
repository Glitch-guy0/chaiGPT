# Story 5.5: Asset Preservation & Explicit Delete

**Epic:** E5 — Assets & RAG
**Pipeline:** 2 — Core Logic
**Depends-On:** 5.1
**Status:** Ready

## Context

Assets referenced in deleted assistant replies are preserved and shown. Users can explicitly delete assets via the DELETE endpoint.

**Affected files:**
- `src/services/asset.service.ts` (add `remove` method)
- `src/app/api/assets/route.ts` (DELETE endpoint)

**Dependencies:** Story 5.1 (asset upload pipeline)

## Acceptance Criteria

**Given** an assistant reply referencing assets is deleted
**When** the conversation is viewed
**Then** the referenced assets are preserved and shown — FR-16

**And** the user may explicitly delete an asset via `AssetsRoute DELETE` — FR-16

## Technical Notes

- Assets are independent of message lifecycle
- DELETE endpoint validates userId ownership
- Physical file deletion from docker volume on explicit delete
- Qdrant vectors also deleted on explicit asset deletion
- Consider: should cascade delete remove vectors too?

## Definition of Done

- [ ] Assets preserved when assistant replies deleted
- [ ] DELETE endpoint validates ownership
- [ ] Physical file deleted from volume on explicit delete
- [ ] Qdrant vectors deleted on asset deletion
- [ ] TypeScript compiles without errors
- [ ] Unit tests pass (Story 2.5)
