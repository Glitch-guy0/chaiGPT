# Story 5.3: Per-Conversation Top-3 Retrieval & Prompt Injection

**Epic:** E5 — Assets & RAG
**Pipeline:** 2 — Core Logic
**Depends-On:** 5.2, 3.3
**Status:** Ready

## Context

Retrieval is scoped to the current conversation's linked assets. Top-3 chunks are retrieved per query and injected into the prompt before completion. Retrieval latency must stay under 300ms p95.

**Affected files:**
- `src/lib/vector/qdrant.ts` (search method)
- `src/services/chat.service.ts` (prompt building)

**Dependencies:** Story 5.2 (chunking/embeddings), Story 3.3 (ChatService)

## Acceptance Criteria

**Given** a chat request in conversation C with linked assets
**When** `QdrantStore.search(embed(lastUser), C, k=3)` runs
**Then** only the top-3 chunks linked to C's assets are returned — FR-14

**And** retrieval latency is < 300 ms p95 — NFR-4

**And** retrieved context is injected into the prompt before completion — FR-15

## Technical Notes

- Filter Qdrant search by `conversationId` metadata
- Use `similaritySearch` with `k=3`
- Inject retrieved context as system message or prompt prefix
- Measure retrieval latency for NFR-4 compliance
- Consider: should context be cached? (Story 5.4 handles this)

## Definition of Done

- [ ] Search scoped to conversation's linked assets
- [ ] Top-3 chunks returned
- [ ] Retrieval latency < 300ms p95
- [ ] Context injected into prompt before completion
- [ ] TypeScript compiles without errors
- [ ] Unit tests pass (Story 2.5)
