# Story 6.4: Edit & Regenerate Controls

**Epic:** E6 — UI Integration & Branch-Aware Experiences
**Pipeline:** 3 — Integration
**Depends-On:** 3.5, 3.6, 6.1
**Status:** Ready

## Context

Edit (latest only) and regenerate controls appear on messages. Only the latest user message is editable; earlier messages are disabled. Stopped assistant messages show a regenerate action.

**Affected files:**
- `src/components/chat-message.tsx` (add controls)

**Dependencies:** Story 3.5 (message editing), Story 3.6 (regenerate), Story 6.1 (auth-gated UI)

## Acceptance Criteria

**Given** the latest user message and its trailing assistant reply
**When** the UI shows controls
**Then** only the latest user message is editable and earlier messages are disabled — FR-10, FR-11, UX-DR6

**And** a stopped assistant message exposes a regenerate action that overwrites the same ID — FR-18, UX-DR6

## Technical Notes

- Edit button: pencil icon on latest user message only
- Regenerate button: refresh icon on stopped assistant messages
- Earlier messages: no controls, dimmed styling
- Edit mode: inline textarea replacing message content
- Regenerate: calls ChatService.regenerate

## Definition of Done

- [ ] Edit button on latest user message only
- [ ] Earlier messages have no controls
- [ ] Regenerate button on stopped assistant messages
- [ ] Edit mode: inline textarea
- [ ] Regenerate calls ChatService.regenerate
- [ ] TypeScript compiles without errors
