# Story 7.2: WebSearchTool (LangChain)

**Epic:** E7 — Web Search (Jina API + LangChain Tool)
**Pipeline:** 3 — Integration
**Depends-On:** 7.1, 1.4
**Status:** Ready

## Context

A LangChain tool wrapping the Jina client, registered with the agent/AiProvider so the LLM can decide when to search the web. Tool invocations and results are captured for citation and observability.

**Affected files:**
- `src/lib/websearch/tool.ts` (implement E1 WebSearchTool interface)
- `src/lib/ai/langchain.ts` (register tool with agent)

**Dependencies:** Story 7.1 (Jina client), Story 1.4 (WebSearchArgsSchema)

## Acceptance Criteria

**Given** the E1 `WebSearchTool` contract and Zod `WebSearchArgsSchema` (FR-28)
**When** the tool is registered with the agent / `AiProvider`
**Then** on invocation it routes to `WebSearchProvider.search` — FR-24

**And** results and source URLs are captured for citation and observability — FR-26

**And** if Jina is unavailable the tool degrades gracefully without crashing the agent

## Technical Notes

- Use LangChain `DynamicTool` or `Tool` class
- Input schema from `WebSearchArgsSchema` (Zod)
- Route to Jina client via WebSearchProvider
- Capture tool invocation in completion path
- Graceful degradation: return empty results on failure
