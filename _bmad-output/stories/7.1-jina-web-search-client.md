# Story 7.1: Jina Web-Search Client (`JinaProvider`)

**Epic:** E7 — Web Search (Jina API + LangChain Tool)
**Pipeline:** 3 — Integration
**Depends-On:** 1.3
**Status:** Ready

## Context

A thin Jina client module that issues live web queries and normalizes results to `{title, url, snippet}`. Fails closed with a clear error when `JINA_API_KEY` is missing.

**Affected files:**
- `src/lib/websearch/jina.ts` (implement E1 WebSearchProvider interface)

**Dependencies:** Story 1.3 (WebSearchProvider interface)

## Acceptance Criteria

**Given** the E1 `WebSearchProvider` contract
**When** `lib/websearch/jina.ts` is implemented
**Then** it reads `JINA_API_KEY` from env, fails closed with a clear error if missing — FR-25

**And** it issues a query to Jina and normalizes results to `{title, url, snippet}` — FR-24

**And** query latency is < 1.5 s p95 — NFR-10

## Technical Notes

- Use Jina AI Search/Reader API (REST endpoint)
- API key from `JINA_API_KEY` env var
- Normalize response to `{ title, url, snippet }` format
- Error handling: timeout, rate limit, missing key
- Consider: retry logic for transient failures

## Definition of Done

- [ ] Jina client reads `JINA_API_KEY` from env
- [ ] Fails closed with clear error when key missing
- [ ] Returns normalized `{ title, url, snippet }` results
- [ ] Query latency < 1.5s p95
- [ ] TypeScript compiles without errors
- [ ] Unit tests pass with mocked Jina (Story 2.5)
