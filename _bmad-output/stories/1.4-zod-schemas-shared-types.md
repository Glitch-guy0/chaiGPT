# Story 1.4: Zod Validation Schemas & Shared App Types

**Epic:** E1 — Types & Contracts
**Pipeline:** 1 — Foundation Setup
**Depends-On:** 1.1
**Status:** Ready

## Context

Every inbound request must be validated against a single contract. This story defines Zod schemas for request validation and shared application types used across the layered architecture. Establishes the validation layer referenced by FR-20.

**Affected files:**
- `src/lib/validation/schemas.ts` (new)
- `src/types/index.ts` (new or modify)
- `src/lib/utils.ts` (new or modify)

**Dependencies:** Story 1.1 (entity types for schema alignment)

## Acceptance Criteria

**Given** `src/types` and `src/lib/validation`
**When** schemas and types are declared
**Then** `lib/validation/schemas.ts` exports `ChatRequestSchema` validating `{ conversationId: uuid, content: string (max 500) }` — FR-20

**And** `ConversationSchema` validates conversation creation input — FR-20

**And** `AssetSchema` validates asset upload input — FR-20

**And** `src/types` exports `ChatRequest`, `ChatResponse`, `Role` shapes matching `02-class.md` view B — FR-21

**And** `lib/utils.ts` defines shared helpers (e.g. `truncate`, `generateId`) — FR-21

**And** `WebSearchArgsSchema` is defined as Zod schema `{ query: string (min 1) }` for the LangChain tool input contract — FR-28

**And** all schemas are importable by route handlers and services

## Technical Notes

- Zod schemas should mirror the entity types from Story 1.1
- `ChatRequestSchema.content` should have `.max(500)` for the character limit
- `WebSearchArgsSchema` will be consumed by the LangChain tool in Story 7.2
- Keep schemas composable — `ConversationSchema` can extend a base schema
- `src/types/index.ts` re-exports entity types for convenience

## Definition of Done

- [ ] `ChatRequestSchema` validates conversationId + content (max 500)
- [ ] `ConversationSchema` validates conversation creation
- [ ] `AssetSchema` validates asset input
- [ ] `WebSearchArgsSchema` validates query string
- [ ] `ChatRequest`, `ChatResponse`, `Role` types exported from `src/types`
- [ ] `lib/utils.ts` has shared helpers
- [ ] All schemas importable from `lib/validation/schemas.ts`
