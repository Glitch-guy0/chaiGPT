# Story 5.6: Edit-Mode Asset References

**Epic:** E5 — Assets & RAG
**Pipeline:** 2 — Core Logic
**Depends-On:** 5.5, 3.5
**Status:** Ready

## Context

In edit mode, trailing assistant asset references remain visible with an option to remove per user action. This preserves context while allowing pruning.

**Affected files:**
- `src/services/message.service.ts` (edit mode logic)

**Dependencies:** Story 5.5 (asset preservation), Story 3.5 (message editing)

## Acceptance Criteria

**Given** the user is in edit mode on the latest message
**When** the trailing assistant reply has asset references
**Then** those references remain visible with an option to remove per user action — FR-17

## Technical Notes

- Edit mode should expose asset references from trailing assistant
- Remove action: disassociate asset from message (not delete asset)
- Asset remains in system, just no longer referenced
- Consider: UI for remove action (button/icon)

## Definition of Done

- [ ] Edit mode shows trailing assistant asset references
- [ ] Remove action disassociates asset from message
- [ ] Asset not deleted, just unreferenced
- [ ] TypeScript compiles without errors
- [ ] Unit tests pass (Story 2.5)
