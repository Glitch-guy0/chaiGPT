# Story 1.3: Integration Module Interface Contracts

**Epic:** E1 — Types & Contracts
**Pipeline:** 1 — Foundation Setup
**Depends-On:** 1.1
**Status:** Ready

## Context

Services depend on interfaces for external integrations (AI, vector store, cache, auth, web search). This story defines those contracts so services program against abstractions, not concrete providers. Each contract specifies the minimal API surface.

**Affected files:**
- `src/lib/ai/provider.ts` (interface)
- `src/lib/vector/qdrant.ts` (interface)
- `src/lib/cache/redis.ts` (interface)
- `src/lib/auth/session.ts` (interface)
- `src/lib/websearch/provider.ts` (interface)
- `src/lib/websearch/tool.ts` (interface)

**Dependencies:** Story 1.1 (entity types for method signatures)

## Acceptance Criteria

**Given** the integrations in `05-architecture.md`
**When** interface types are declared
**Then** `AiProvider` interface declares `complete(messages: Message[])` returning `Promise<string>` and `streamChat(messages: Message[], onChunk: (chunk: string) => void)` returning `Promise<void>` — FR-22

**And** `QdrantStore` interface declares `embed(text: string)`, `search(vec: number[], convId: string, k: number)` returning chunk results with asset/citation refs, and `upsertChunks(assetId: string, chunks: Chunk[])` — FR-14

**And** `RedisCache` interface declares `get(key: string)` and `set(key: string, value: string, ttlSeconds: number)` — NFR-2

**And** `auth` interface declares `session()` returning `Promise<{ userId: string }>` — FR-1, FR-23

**And** `WebSearchProvider` interface declares `search(query: string)` returning `Promise<WebSearchResult[]>` where `WebSearchResult` is `{ title: string, url: string, snippet: string }` — FR-24

**And** `WebSearchTool` interface declares `run(args: { query: string })` routed to `WebSearchProvider` — FR-27, FR-28

## Technical Notes

- `AiProvider` wraps LangChain `ChatOpenAI` streaming — the interface is provider-agnostic
- `QdrantStore` wraps `@langchain/qdrant` — interface should not expose LangChain internals
- `WebSearchTool` uses Zod `WebSearchArgsSchema` for input validation (defined in Story 1.4)
- `auth` wraps Clerk `auth()` from `@clerk/nextjs/server` — interface returns only `userId`
