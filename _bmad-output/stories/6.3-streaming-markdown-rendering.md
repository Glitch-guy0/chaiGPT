# Story 6.3: Live Streaming & Markdown Rendering

**Epic:** E6 — UI Integration & Branch-Aware Experiences
**Pipeline:** 3 — Integration
**Depends-On:** 3.3, 6.1
**Status:** Ready

## Context

Streamed tokens render live as Markdown, with complete/stopped final state. Web-source citations are shown when web search was used.

**Affected files:**
- `src/components/chat-message.tsx` (modify — streaming render)
- `src/components/markdown-renderer.tsx` (new or modify)

**Dependencies:** Story 3.3 (ChatService SSE streaming), Story 6.1 (auth-gated UI)

## Acceptance Criteria

**Given** an SSE stream from `ChatService`
**When** tokens arrive
**Then** they render progressively with a complete/stopped final state — FR-19, FR-6, UX-DR3

**And** message content is rendered as Markdown — UX-DR4, brief #7

**And** streamed assistant replies may include web-source citations when web search was used — FR-26

## Technical Notes

- Use `react-markdown` for Markdown rendering
- SSE EventSource for token streaming
- Progressive rendering: append tokens to message state
- Final state: show complete/stopped indicator
- Citation rendering: inline links or footnotes for web sources

## Definition of Done

- [ ] Tokens render progressively via SSE
- [ ] Complete/stopped final state shown
- [ ] Markdown rendered correctly
- [ ] Web-source citations displayed
- [ ] TypeScript compiles without errors
