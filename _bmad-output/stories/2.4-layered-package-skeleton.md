# Story 2.4: Layered Package Skeleton

**Epic:** E2 — Foundation & Infra
**Pipeline:** 1 — Foundation Setup
**Depends-On:** 1.4
**Status:** Ready

## Context

The layered architecture (routes → services → repositories/integrations) needs its directory structure in place. This story creates the package skeleton per `01-package.md` so all features follow the approved concern-separated architecture.

**Affected files:**
- `src/app/` (Next.js App Router — exists)
- `src/services/` (new directory)
- `src/lib/db/` (repositories — new)
- `src/lib/ai/` (new)
- `src/lib/vector/` (new)
- `src/lib/cache/` (new)
- `src/lib/auth/` (new)
- `src/lib/validation/` (new)
- `src/lib/websearch/` (new)
- `src/types/` (new)

**Dependencies:** Story 1.4 (shared types/schemas to place)

## Acceptance Criteria

**Given** the project root
**When** I inspect `src/`
**Then** the structure matches `01-package.md`: `app/`, `services/`, `lib/db`, `lib/ai`, `lib/vector`, `lib/cache`, `lib/auth`, `lib/validation`, `lib/websearch`, `types/`

**And** dependency direction is `app → services → {repositories | ai | vector | cache | websearch}` with no port/adapter layer — NFR-1

**And** no circular dependencies exist between layers
