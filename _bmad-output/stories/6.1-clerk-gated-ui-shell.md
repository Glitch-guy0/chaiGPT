**Epic:** E6 — UI Integration & Branch-Aware Experiences
**Pipeline:** 3 — Integration
**Depends-On:** 2.3, 3.2
**Status:** Ready

## Context

The existing flat chat UI is gated by Clerk authentication. Unauthenticated users are redirected to sign-in. Signed-in users see only their own conversations.

**Affected files:**
- `src/app/page.tsx` (modify — add auth gate)
- `src/components/` (existing UI components)

**Dependencies:** Story 2.3 (Clerk auth middleware), Story 3.2 (ConversationService)

## Acceptance Criteria

**Given** the existing flat chat UI (sidebar + composer)
**When** an unauthenticated user loads it
**Then** they are redirected to sign-in — FR-3

**And** signed-in users see only their own conversations — FR-2, UX-DR1

- Preserve existing UI shell structure
- Consider: Clerk's `<SignedIn>` wrapper or middleware-level redirect

## Definition of Done

- [ ] Unauthenticated users redirected to sign-in
