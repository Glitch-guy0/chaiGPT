# Story 2.5: Testing Foundation (Vitest + ≥80% Coverage Gate)

**Epic:** E2 — Foundation & Infra
**Pipeline:** 1 — Foundation Setup
**Depends-On:** 2.4
**Status:** Ready

## Context

A test harness with Vitest, repository/service fixtures, and a coverage gate enforcing ≥80% of services + repositories. External deps (OpenAI, LangChain, Qdrant, Jina, Clerk) must be mockable for offline/deterministic tests.

**Affected files:**
- `vitest.config.ts` (new)
- `src/**/*.test.ts` (colocated test files)
- `package.json` (add test scripts)
- CI config (add coverage gate step)

**Dependencies:** Story 2.4 (layered skeleton for test file placement)

## Acceptance Criteria

**Given** the project root after E2.1–E2.4 are in place
**When** the test foundation is set up
**Then** Vitest is configured with a coverage reporter for `src/services` and `src/lib/db/repositories`

**And** seedable test fixtures exist for `ConversationRepository`, `MessageRepository`, and `AssetRepository` against a disposable Postgres (or in-memory TypeORM) instance

**And** a CI step fails the build if service + repository coverage is below 80% — NFR-7

**And** test files are colocated with source (`*.test.ts` next to each service/repository) — FR-29

**And** OpenAI, LangChain, Qdrant, Jina, and Clerk are mockable in unit tests — FR-30, NFR-8

**And** the coverage gate enforces ≥80% and fails CI below threshold — FR-31

## Technical Notes

- Vitest config should use `coverage.include: ['src/services/**', 'src/lib/db/repositories/**']`
- Coverage threshold: `statements: 80, branches: 80, functions: 80, lines: 80`
- Use `vi.mock()` for external deps
- Fixtures should use factory functions returning test data
- Consider `vitest-environment-node` or custom environment for TypeORM
- CI: add `npm run test:coverage` step that fails below 80%

## Definition of Done

- [ ] Vitest configured with coverage for services + repositories
- [ ] Coverage threshold set to ≥80%
- [ ] Test fixtures for all 3 repositories
- [ ] Mocking patterns for OpenAI, LangChain, Qdrant, Jina, Clerk
- [ ] `npm run test` runs successfully
- [ ] `npm run test:coverage` enforces ≥80% gate
- [ ] CI step added for coverage gate
