# Story 3.4: AiProvider Concrete Module (Streaming)

**Epic:** E3 — Conversation & Message Core
**Pipeline:** 2 — Core Logic
**Depends-On:** 1.3
**Status:** Ready

## Context

The concrete AiProvider wraps LangChain `ChatOpenAI` for streaming completions. Services depend on the E1 interface; this module is the only place that touches LangChain directly.

**Affected files:**
- `src/lib/ai/langchain.ts` (implement E1 AiProvider interface)

**Dependencies:** Story 1.3 (AiProvider interface contract)

## Acceptance Criteria

**Given** the `lib/ai/langchain.ts` module implementing the E1 `AiProvider` contract
**When** `ChatService` calls `AiProvider.streamChat(messages, onChunk)`
**Then** tokens are emitted to `onChunk` and the stream completes

**And** the default model is `gpt-4o-mini` and can be swapped by changing only this module, not the services — FR-22

## Technical Notes

- Use `ChatOpenAI` from `@langchain/openai`
- `streamChat` should use `.stream()` method
- `complete` should use `.invoke()` for non-streaming
- Model configurable via env var or constructor param
- Handle OpenAI errors gracefully (rate limits, network)
- Export a singleton or factory for the provider

## Definition of Done

- [ ] `AiProvider` implements `complete` and `streamChat`
- [ ] Default model is `gpt-4o-mini`
- [ ] Model swappable without changing services
- [ ] Streaming emits chunks to callback
- [ ] TypeScript compiles without errors
- [ ] Unit tests pass with mocked OpenAI (Story 2.5)
