# Story 7.3: Web Context Injection

**Epic:** E7 — Web Search (Jina API + LangChain Tool)
**Pipeline:** 3 — Integration
**Depends-On:** 7.2, 3.3
**Status:** Ready

## Context

When the LLM invokes web search, Jina web context is injected into the prompt alongside Qdrant RAG. Each web result carries its source URL for citation. Web context supplements RAG, not replaces it.

**Affected files:**
- `src/services/chat.service.ts` (prompt building with web context)

**Dependencies:** Story 7.2 (WebSearchTool), Story 3.3 (ChatService)

## Acceptance Criteria

**Given** a chat request where the LLM invokes web search
**When** `ChatService` builds the prompt
**Then** Jina web context is injected before completion alongside Qdrant RAG — FR-15, FR-26

**And** each web result carries its source URL for citation — FR-26

**And** web context supplements the per-conversation RAG and does not replace it — FR-14

## Technical Notes

- Build prompt with both RAG context and web context
- Web context injected as additional system message or prompt section
- Each web result formatted with title, URL, snippet
- Citation format: `[Source: title](url)` or similar
- RAG context still injected regardless of web search

## Definition of Done

- [ ] Web context injected alongside RAG context
- [ ] Source URLs included for citation
- [ ] RAG context not replaced by web context
- [ ] Prompt building handles both context sources
- [ ] TypeScript compiles without errors
- [ ] Unit tests pass (Story 2.5)
