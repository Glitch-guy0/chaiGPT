# Story 4.1: Branch Creation (Sibling Under Same Parent)

**Epic:** E4 — Branching
**Pipeline:** 3 — Integration
**Depends-On:** 3.2
**Status:** Ready

## Context

Users can branch from any assistant message to explore alternatives. A branch creates a new conversation sharing the same `rootConversationId`, with the branched message as a sibling under the same `parentId`.

**Affected files:**
- `src/services/conversation.service.ts` (add `branch` method)

**Dependencies:** Story 3.2 (ConversationService)

## Acceptance Criteria

**Given** an assistant message with `parentId` P in conversation C
**When** `ConversationService.branch(id, messageId, userId)` runs
**Then** a new conversation is created sharing `rootConversationId` of C and the branched message becomes a sibling under the same `parentId` — FR-8

**And** the new branch is scoped to the same `userId` — FR-2

## Technical Notes

- Create new Conversation with `rootConversationId` = C's root (or C.id if C is root)
- Copy messages from root to branch point
- New message is a sibling: same `parentId` as the original
- `lastMessageId` points to the new message
- Consider: deep copy messages or reference sharing?

## Definition of Done

- [ ] `branch` creates new conversation with shared `rootConversationId`
- [ ] Branched message is sibling under same `parentId`
- [ ] New branch scoped to same `userId`
- [ ] TypeScript compiles without errors
- [ ] Unit tests pass (Story 2.5)
