# Story 6.2: Branch-Aware Sidebar

**Epic:** E6 — UI Integration & Branch-Aware Experiences
**Pipeline:** 3 — Integration
**Depends-On:** 4.1, 6.1
**Status:** Ready

## Context

The sidebar shows only sibling branches of the active branch, not the full tree. This prevents users from getting lost in complex branch structures.

**Affected files:**
- `src/components/sidebar.tsx` (modify — branch-aware rendering)

**Dependencies:** Story 4.1 (branch creation), Story 6.1 (auth-gated UI)

## Acceptance Criteria

**Given** a branched conversation with siblings
**When** the sidebar renders
**Then** only siblings of the active branch are shown, not the entire tree — FR-9, UX-DR2

## Technical Notes

- Filter conversations by `rootConversationId` matching active branch
- Sort siblings by `createdAt` for consistent ordering
- Highlight active branch in sidebar
- Consider: nested indentation for branch depth
