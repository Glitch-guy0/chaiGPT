## Retrospective Findings & Discussion

### What Went Well ✅

1. **Seamless Auth Integration:** Clerk middleware and frontend provider worked out-of-the-box with zero routing leaks.
2. **Smooth SSE Markdown Stream:** Token streaming renders without UI flicker or markdown parser re-render loops.
3. **Branch Tree Visual Clarity:** Sidebar hierarchy accurately mirrors sibling message nodes and parent lineage.

### What Could Be Improved ⚠️

1. **Network Disruption Resiliency:** SSE connection dropouts require manual page refresh instead of automatic client retry.
2. **Upload Progress Feedback:** Large paste-to-txt conversion (> 500 chars) lacks an explicit progress bar during staging.
3. **E2E Test Coverage for UI Transitions:** Playwright tests needed for multi-branch navigation state assertions.
